## 全栈启动（已验证跑通）

端口分配：data-hub 8120 / api-server 3100 / studio-web 5173 / 商城后端 5000 / 商城前端 5174

启动命令：
- data-hub：`apps/data-hub` 下 `python app.py`（需 HUB_TOKENS）
- api-server：`node apps/api-server/src/server.js`（需 DATA_HUB_* 三个变量）
- studio-web：`node node_modules/vite/bin/vite.js apps/studio-web --host 127.0.0.1 --port 5173`
- 商城后端：`F:\Python_code\Flask项目\flask_shop` 下 `.venv/Scripts/python.exe run_dev_api.py`（5000）
- 商城前端：`F:\Python_code\Flask项目\mall` 下 `node node_modules/vite/bin/vite.js --host 127.0.0.1 --port 5174`
  （mall 默认 5173，与 studio 冲突，必须改 5174；其 axios baseURL=/api/c，vite 代理 /api→5000 不重写路径）

关键路由前缀：product_bp 无前缀（/products/...）、c_bp=/api/c、agents_bp=/api/agents
Flask 根路径 / 是 404，健康检查走 /health/

已知：OpenRouter 免费模型 429/404，LLM 不可用时客服走规则兜底，链路仍可应答；
`data.knowledge.cards` 与 `data.reply` 是客服响应的正确字段（不是 message）
